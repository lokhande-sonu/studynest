# Studynested Deployment Package

This package contains everything needed to deploy Studynested to your shared hosting server.

## Quick Start

1. Read `DEPLOY_INSTRUCTIONS.txt` first
2. Upload files via FileZilla or SCP
3. Configure `.env` file
4. Import database
5. Run `./deploy-shared-hosting.sh`
